## Flagship — AI Sales Funnel System

A complete capture-to-conversion system where every stage is one connected machine
instead of a stack of disconnected tools.

```
Traffic → Engagement → Qualification → Recommendation → Sales Conversation
        → Purchase / Booking → Follow-up → Recovery
```

| Stage | What the system does |
| --- | --- |
| **AI sales assistant** | A conversational agent on the landing page that reads intent and guides the visitor. |
| **Lead capture** | A short form or in-chat capture straight into the CRM view. |
| **Qualification** | Configurable questions with per-answer scores across five axes — budget, authority, need, timing, fit. |
| **Lead scoring** | A transparent 0–100 score and a Hot / Warm / Cold read, with the reasoning shown. |
| **Recommendation** | Matched from the business's real catalogue — services, homes or products — never invented. |
| **Offer** | A live, time-boxed offer with a real expiry. |
| **Booking / checkout** | A real appointment or viewing slot (double-booking prevented), or an add-to-cart checkout. |
| **Follow-up** | A scheduled sequence with stop conditions — no drip after the customer has acted. |
| **Recovery** | Abandoned leads and carts worked with the smallest incentive that fits the objection. |
| **CRM & analytics** | Every lead, stage and conversion in one business console. |

**Built with:** JavaScript (ES Modules), a config-driven architecture (one object retargets
the whole funnel to a new industry), an intent-loop conversational engine, a five-axis
qualification engine, and namespaced local persistence — no framework, deployable to any
static host.
